# 通用常见错误

1. **工程目录不存在** → 询问用户是否创建
2. **引脚冲突** → 检查 hardware.json 引脚分配
3. **寄存器地址错误** → 只使用 datasheet.json 确认的寄存器
4. **代码区域丢失** → 检查 USER CODE 区域标记
5. **编译错误** → 检查 include 路径和函数声明
6. **IDE 未安装** → 提示用户安装
7. **芯片包未安装** → 提示用户安装芯片包
8. **SDK 未找到** → 提示用户下载 SDK
9. **I2C 地址错误** → 检查 datasheet.json
10. **时钟配置错误** → 确保外设时钟已使能
11. **TimePiece 引用错误** → 为本项目重新创建 TaskList.h/c
12. **外部变量未声明** → 添加 extern 声明
13. **函数未声明** → 在 .h 文件中添加声明
